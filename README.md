# Project Name : QuickReserve [Assignment Category: 03]

## Here is the short description about this Project

This is Room Reservation platform where you can create, Read, update, delete/cancel Rooms Reservation..


## Key features of this Project

1. Displaying all rooms on Room Page :
```bash
  `fetching`  from MongoDb rooms Collection. 
```
2. In `Home` hotel infomations, maps, featured rooms with easy booking `book button` and there is a review section where reviews are fetch by timestamp. 

3.In`Rooms ` page user can see room cards  by clicking `Room Cards` user Can see room details also can have a button for book the room . .

4. In `Room Details ` in this page user will see specific room details authenticated user can book the room with a form. 

5. In `My Bookings` page logged user can see their Booked rooms also they can update and cancel their booked rooms by clicking update and cencel button. also can give review by clicking review button.
